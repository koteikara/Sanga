# 公開サイト入口ページ（プロトタイプ）

作成日: 2026-08-26

## 目的

`public/index.html` を各ツールへの入口として作り直すにあたり、見た目と動きを本番実装の前に確認する。設計は `docs/site-index.md` を参照。

静止画の設計案ではアニメーションの速さや主張の強さを判断できないため、動くものを先に作って確認する。

## 確認すること

| 観点 | 見るところ |
| --- | --- |
| 配色 | 紫を基調にしたときの雰囲気。既存の日程ページ（紫）・スカッド（緑）との距離感 |
| 背景の動き | 速さと主張の強さ。カードの文字が読みにくくならないか |
| キャラクター | ふわふわの振れ幅と周期、まばたきの間。うるさくないか |
| 導線 | 装飾が各ツールへのリンクを邪魔していないか |
| データ駆動 | `tools.sample.json` からセクション分けが破綻せず組み立てられるか |
| 読み込み失敗 | 通信を切っても導線が残るか |
| 動きを減らす設定 | OSの「視差効果を減らす」で動きが止まるか |
| 背景の可読性 | ネビュラの明るい部分に文字が重なっても読めるか |
| 負荷 | スクロールが引っかからないか。発熱・電池の減りが気になるほどでないか |

## 背景のネビュラ

紫の霧が流れる背景を `nebula.js` で描く。FBMノイズをドメインワープさせたものに、ポインタドリフト、明滅、ビネットをかけている。

**生のWebGLで書いている。** この表現に必要なのは「画面いっぱいの三角形1枚にフラグメントシェーダー」だけで、シーングラフもカメラもジオメトリも出番がない。three.js を読ませると357KB（gzip 127KB）増えるが、得られるものがない。実装は約8KB。

進行的強化として足している。WebGLが使えない、初期化に失敗した、`?nebula=off` を付けた、のいずれでもCSSのぼかし背景がそのまま残る。

| 状況 | 表示 |
| --- | --- |
| 既定 | ネビュラ。CSSのぼかしは引っ込む |
| WebGL不可・初期化失敗 | CSSのぼかし。コンソールに理由を出す |
| `?nebula=off` | CSSのぼかし。実機で見比べるため |
| 動きを減らす設定 | ネビュラを1枚だけ描いて静止させる |
| 画面外・別タブ | 描画を止める |

負荷を抑えるため、画素密度は2倍で頭打ちにしている。フラグメントシェーダーの負荷は面積に比例するため、3倍の端末では2.25倍になる。

## 実装の方針

* 追加の依存なし。CSSと生のWebGLだけで作る。
* 動かすのは `transform` と `opacity` だけにして、レイアウトの再計算を起こさない。
* ぼかしは `filter: blur` ではなく放射グラデーションで作る。端末によって描画コストが高いため。
* `prefers-reduced-motion: reduce` ですべての動きを止める。

## キャラクターについて

サイト独自のオリジナルとして作る。次に似せない。

* 京都サンガF.C.の公式マスコット。非公式サイトのため権利上の問題になる。
* 既存のゲームキャラクター。スポンサー企業のものであっても利用許諾にはならない。

平たい図形と点目2つという作風自体はよくある意匠だが、造形は独自のものにする。現状は次の2体。

| キャラ | 造形 | 由来 |
| --- | --- | --- |
| 五角形寄りのブロブ | 角を丸めた五角形、薄紫 | サッカーボールの面 |
| 角丸スクエア | 角丸の正方形、水色 | 特定のモチーフを持たない相方 |

## 未確定

* キャラクターの体数、配置、スクロールに反応させるか。
* 背景に別の要素（芝の縞、粒子）を足すか。
* カードにアイコンや画像を持たせるか。持たせる場合は `tools.json` に項目を足す。

## 確認方法

GitHub Pagesの「GitHub Pages確認環境」ワークフローを対象ブランチで実行し、次を開く。

```text
https://<GitHub Pagesのドメイン>/experiments/site-index/prototype.html
```

`tools.sample.json` はプロトタイプ用のサンプル。本番では `public/data/tools.json` を使う。
