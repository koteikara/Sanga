# ベンチ強調オプション（比較プロトタイプ）

作成日: 2026-08-21

## 目的

予想スカッドのベンチをもっと目立たせたい、という要望に対し、現行の見せ方を残したまま
オプションで切り替えられるかを、移植前に見た目で確認する。

確認するのは次の2軸の組み合わせ（4通り）。

| | 標準 | 大きめ |
| --- | --- | --- |
| チップ（現行） | A | B |
| 背番号タイル | C | D |

名前の表記は本番の「日本語名を併記」に従属させる想定のため、この軸は増やしていない。

## 確認方法

GitHub Pagesで次を開く。

```text
https://koteikara.github.io/Sanga/experiments/bench-emphasis/prototype.html
```

キャンバスは本番ページ `squad.html` を同一オリジンのiframeで読み込み、ベンチだけを
差し替えている。配置計算・画像・スタイル切替は本番のコードがそのまま動くので、
移植したときの見え方と一致する。

操作できるのは、キャンバス幅（320 / 375 / 420px）、控えの人数（6 / 9 / 12人）、
スタイル（8種類）、タイルの名前（省略名を出す / 背番号だけ）、大きめの効かせ方。

控えは見分けにくい組み合わせ（マセイオ／ウェベルトン、福田／福岡、平岡／平賀／平戸、
加藤／加藤蓮）を意図的に含めている。

## 構成

| ファイル | 内容 |
| --- | --- |
| `prototype.html` | 操作パネルと4枚の比較枠 |
| `prototype.js` | iframeの操作、ベンチの組み替え、名前の圧縮 |
| `prototype.css` | 比較画面そのものの見た目 |
| `bench-overlay.css.js` | iframeへ差し込むベンチのCSS。**本番へ移植するのはこの中身** |
| `name-short.js` | ベンチ表示用の省略名39人分。確定後は `players.json` の `nameShort` へ移す |

## 設計の要点

* 見せ方はキャンバスの `data-bench-format`（chip / tile）で分岐する。
  `:has()` は iPhone Safari 15系にないため使わない。
* 大きさは `--bench-emphasis`（1 / 1.35）の**倍率**で持ち、人数に応じた既存の
  自動縮小 `--bench-scale` と掛け算する。見せ方が増えても、はみ出しを防ぐ仕組みは1本のまま。
* フッターの上限だけ見せ方ごとに変える（chip 24% / tile 32%）。
  ピッチの `min-height:60%` は変えない。
* 長い省略名は、カード名と同じ「収まらないときだけ横方向へ圧縮」を使う。

## 実測（2026-08-21・Chromium）

420px・控え9人・モダンでの比較。

| | ベンチ1件の幅 | フッター比 | ピッチ比 | カード高さ |
| --- | --- | --- | --- | --- |
| A チップ×標準 | 65.2px | 11.4% | 69.9% | 75.1px |
| B チップ×大きめ | 86.6px | 17.1% | 64.2% | 72.0px |
| C タイル×標準 | 28.3px | 11.5% | 69.9% | 75.1px |
| D タイル×大きめ | 29.4px | 11.8% | 69.6% | 75.1px |

320px・控え12人でも、4通りとも見切れは発生しない。

## わかったこと

1. **タイルでは「大きめ」がほとんど効かない。**
   本番の `layoutPitch()` は、カードが下限（70px）に張り付くとベンチ側を自動で縮めて
   ピッチの取り分を増やす。Dではこれが働き、`--bench-scale` が 0.86 から 0.66 へ下がって
   指定した1.35倍を打ち消していた（円は28.3→29.4pxで4%しか増えない）。
2. **縮小率を戻すだけでは解決しない。**
   ベンチ優先として `--bench-scale` を基準値へ戻すと円は38.3pxまで大きくなるが、
   カード高さを再計算していないため、ピッチ下端のカード（GK）がはみ出す。
   本番で対応するなら、大きめのときだけカード高さの下限を緩めたうえで `fitCards()` を
   通す必要がある。
3. **シンプルとの相性が良い。**
   シンプルはスタメンも円なので、タイル表示にすると全体が一つのデザインとしてまとまる。
4. **省略名は4文字前後で頭打ち。**
   名前欄の幅は円の直径に比例するため、幅や人数によらず約4.2文字ぶん。
   「ウェベルトン」「トレヴィザン」は横圧縮がかかるが判読できる。

## 未確認・次の判断

* 背番号タイル画像は `docs/source-and-license.md` で利用許諾が未確認と整理されている素材。
  ベンチにも使うと使用箇所が増えるため、暫定判断の範囲内として扱ってよいか要確認。
* 「大きめ」をタイルで実際に効かせるか（＝カード高さの下限を緩めるか）の判断。
* iPhone Safariでの表示とPNG生成は未確認。
* 本番移植時の検証は、既存の全組み合わせに掛けず、
  「4パターン × 8スタイル × 3幅 × 控え12人 × 代表フォーメーション2 = 192通り」を追加する想定。
