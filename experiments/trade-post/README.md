# 求・譲 投稿ツール（プロトタイプ）

作成日: 2026-09-09

設計は `docs/trade-post-design.md` を正とします。ここは移植前に見た目と操作感を確かめるための検証用です。
本番の `public/TradePost/index-v1.html` はまだ改修していません。

## 目的

現行ツールは、ほぼ使われていません。原因は**投稿が誰にも見つからない形で出力されていた**ことでした
（実在しないタグ `#京都サンガ交換希望` を出力し、入力は自由文1行）。
作り直しの方針を、設計文書だけで決めずに触って確かめます。

| 確認したいこと | 見るところ |
| --- | --- |
| 商品と背番号を「選ぶ」だけで実際の投稿と同じ形になるか | 「投稿をつくる」の投稿文 |
| 背番号を40件から選ぶ操作がスマホで成立するか | 譲・求の盤。指で押せるか、長すぎないか |
| 文字数が重み付き280で実用的な長さに収まるか | 投稿文の下のカウンタ |
| 受け渡しを試合から選ぶ形が合っているか | 「受け渡し」 |
| 「さがす」でいま出ている投稿へ実際に届くか | 「募集をさがす」の検索リンク |
| 商品名の未確認表示が邪魔にならないか | 商品を選んだときの注記 |

## 確認方法

GitHub Pagesで次を開きます。

```text
https://koteikara.github.io/Sanga/experiments/trade-post/prototype.html
```

`fetch` でJSONを読むため、手元ではファイルを直接開かず、HTTP経由で開きます。

```bash
python3 -m http.server 8000
# http://localhost:8000/experiments/trade-post/prototype.html
```

## 出力の例

```text
【交換】ユニ型缶バッジ（1st）
譲 2.8.34.50
求 9.17

9/11(金) ホーム柏戦 / 郵送も可
検索からお気軽にお声かけください

#サンガガチャ交換 #京都サンガ
```

重み付き146文字（上限280）。背番号のドット区切り、商品名を1回だけ書く形、受け渡しを試合で示す形は、
実際の投稿に合わせています（`docs/trade-post-design.md`「Xでの交換の実態」）。

## 現行ツールから変えたところ

| 現行 | プロトタイプ |
| --- | --- |
| `#京都サンガ交換希望`（0件のタグ）を出力 | 実在するタグだけを `goods.sample.json` から出力 |
| 入力文をそのままタグ化（`#ホーム浦和戦Sメイン`） | タグは商品マスタが持つものだけ |
| 譲・求が自由文1行 | 商品を選び、背番号を複数選ぶ |
| 受け渡しが自由文 | `matches.json` の今後6試合から選ぶ |
| 文字数を生の `length` で140と比較 | 重み付き280で比較 |
| 投稿文が `readonly` で直せない | そのまま直せる |
| `document.execCommand("copy")` と `alert()` | `navigator.clipboard`、失敗時は文言で案内 |
| `twitter.com/intent/tweet` | `x.com/intent/post` |
| 声をかけてよい合図がない | 「検索からお気軽にお声かけください」を既定で入れる |
| 探す手段がない | 「募集をさがす」タブ |

## 確認済み（2026-09-09、Chromium 390px）

- 横スクロールが出ない（390 / 390）
- タップ対象の高さ: タブ44px、チップ44px、背番号48px、試合44px、チェック44px、ボタン54px、select 45px
- 選んだ背番号がドット区切りで並ぶ（`譲 2.8.34.50`）
- 「番号は問わない（同種）」で `求 同種` になる
- 期限付き移籍中の選手（#2）が薄く出るが選べる。発売時点で在籍していた選手のグッズは交換対象に出るため
- 「さがす」の検索語が `サンガ 缶バッジ 譲`、背番号を1つ選ぶと `サンガ 缶バッジ 譲 34`
- JavaScriptエラーなし

## 未確認・判断が要ること

1. **商品の正式名称。** `goods.sample.json` の `tentative: true` は未確認です。公式表記と突き合わせてください。
2. **背番号40件の盤が2つ並ぶ長さ。** 実機で許容できるか。畳む案もあります。
3. **画像を出すか。** いまはテキストだけです。テキストで足りるなら足しません。
4. **iPhone Safari。** 未確認です。特にコピーの挙動。
5. **商品マスタの更新運用。** ガチャは試合ごとに新商品が出ます。誰がいつ追加するか決めていません。
