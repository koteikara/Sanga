# 求・譲 投稿ツール（プロトタイプ）

作成日: 2026-09-09

設計は `docs/trade-post-design.md` を正とします。ここは移植前に見た目と操作感を確かめるための検証用です。
本番の `public/TradePost/index-v1.html` はまだ改修していません。

## 目的

現行ツールは、ほぼ使われていません。原因は**投稿が誰にも見つからない形で出力されていた**ことでした
（実在しないタグ `#京都サンガ交換希望` を出力し、入力は自由文1行）。
作り直しの方針を、設計文書だけで決めずに触って確かめます。

| 確認したいこと | 見るところ |
| --- | --- |
| 商品と背番号を「選ぶ」だけで実際の投稿と同じ形になるか | 「投稿をつくる」の投稿文 |
| 商品を複数組のせたときに読めるか | 「商品をもう1つ足す」を押してから投稿文と画像 |
| 選手名を添えて280文字に収まるか | 投稿文の下のカウンタ。外したときとの差 |
| 背番号を40件から選ぶ操作がスマホで成立するか | 譲・求の盤。指で押せるか、組が増えても長すぎないか |
| 文字数が重み付き280で実用的な長さに収まるか | 投稿文の下のカウンタ |
| 画像がXのタイムラインで読めるか | 画像欄。実機で見る |
| 「さがす」でいま出ている投稿へ実際に届くか | 「募集をさがす」の検索リンク |

## 確認方法

GitHub Pagesで次を開きます。

```text

```

## 出力の例

商品を2組のせた場合です。

```text
【交換】京都サンガ
譲）ユニ型缶バッジ（1st） 2福田 8米本 34トレヴィザン 50鈴木
求）同種 9ラファエル 17ソウザ
譲）VICTORY ガチャ【第一弾】 10福岡 44佐藤 62志知
求）同種 83パーサ

9/11(金) ホーム柏戦 / 郵送も可
検索からお気軽にお声かけください

#サンガガチャ交換 #京都サンガ
```

「同種」は「同じもの」の意味です。組の中で商品名を1回書き、求の行がそれを受けます。
書き方はすべて実際の投稿に合わせています（`docs/trade-post-design.md`「Xでの交換の実態」）。

背番号には選手名を添えます。背番号だけだと覚えていない人が確認したり取り違えたりするためです。
名前は1人あたり重み8前後かかるので、**「背番号に選手名を添える」で外せます**。
外すと `譲）ユニ型缶バッジ（1st） 2.8.34.50` に戻り、上の例は261文字から203文字になります。

画像も同時に作ります（1200×675のPNG、`canvas` の2Dだけで描画）。
画像は文字数の制約が無いため、選手名を常に添えます。

## 現行ツールから変えたところ

| 現行 | プロトタイプ |
| --- | --- |
| `#京都サンガ交換希望`（0件のタグ）を出力 | 実在するタグだけを `goods.sample.json` から出力 |
| 入力文をそのままタグ化（`#ホーム浦和戦Sメイン`） | タグは商品マスタが持つものだけ |
| 譲・求が自由文1行 | 商品を選び、背番号を複数選ぶ。商品は複数組のせられる |
| 受け渡しが自由文 | `matches.json` の今後6試合から選ぶ |
| 文字数を生の `length` で140と比較 | 重み付き280で比較 |
| 投稿文が `readonly` で直せない | そのまま直せる |
| `document.execCommand("copy")` と `alert()` | `navigator.clipboard`、失敗時は文言で案内 |
| `twitter.com/intent/tweet` | `x.com/intent/post` |
| 声をかけてよい合図がない | 「検索からお気軽にお声かけください」を既定で入れる |
| 背番号だけで選手が分からない | 背番号に選手名を添える（テキストは外せる、画像は常時） |
| 画像がない | 譲・求を色で分けた画像を出す |
| 探す手段がない | 「募集をさがす」タブ |

## 確認済み（2026-09-09、Chromium 390px）

- 横スクロールが出ない（390 / 390）
- タップ対象の高さ: タブ44px、チップ44px、背番号48px、試合44px、チェック44px、ボタン54px、select 45px
- 商品2組・背番号10件・選手名ありで261/280文字。選手名を外すと203文字
- 2組目以降が `求）同種` で受ける
- 種別（1st/2nd）を持つ商品でだけ種別欄が出る（VICTORY ガチャでは出ない）
- 組を消すと文面と画像から消える
- 画像に商品名・譲・求・受け渡し・IDが入り、背番号の下に選手名が出て、文字が切れていない
- 「さがす」の検索語が `サンガ 缶バッジ 譲`、背番号を1つ選ぶと `サンガ 缶バッジ 譲 34`
- JavaScriptエラーなし
