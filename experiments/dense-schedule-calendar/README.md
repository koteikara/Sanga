# 過密日程カレンダー（検証用プロトタイプ）

作成日: 2026-09-08

## 目的

2026/27シーズンの試合と試合の「間隔」の詰まり具合を、スマートフォンでスクロールしながら
把握できるかを確かめる。設計の意図と用語は `docs/dense-schedule-calendar.md` を正とする。

文章と静的モックアップだけでは決まらない次の点を、実データで触って確かめるためのもの。

| 確認したいこと | 見るところ |
| --- | --- |
| 全日を並べて破綻しないか（334日・約9,900px） | 全体をスクロール |
| 危険度の色分けが「過密」を伝えるか | 10月・11月 |
| 月見出しの貼り付きで現在地を見失わないか | 月をまたぐところ |
| ミニマップで年間の density を掴めるか | 右端の帯 |
| 未確定日程の見せ方が誤解を生まないか | 2027年2月〜5月の点線の箱と斜線 |
| 中断期間を「安全（緑）」と描いてよいか | 2027年1月 |
| 狭い画面で対戦相手名が読めるか | 幅320pxでACL勢の長い名前 |

## 確認方法

GitHub Pagesで次を開く。

```text
https://koteikara.github.io/Sanga/experiments/dense-schedule-calendar/prototype.html
```

`fetch` で日程JSONを読むため、ローカルではファイルを直接開かずHTTP経由で開く。

```bash
python3 -m http.server 8000
# http://localhost:8000/experiments/dense-schedule-calendar/prototype.html
```

日程は複製を置かず `public/data/matches.json` の正本をそのまま読む。GitHub Pagesでは
`public/` が直下に展開され、手元ではリポジトリ直下が根になるため、`../../data/matches.json` と
`../../public/data/matches.json` を順に試す。手元で開くと前者が1回404になるが、後者で読めていれば正常。

## 元の指示との違い

添付モックアップからは、実データと既存ページに合わせて次を変えている。

| 項目 | モックアップ | このプロトタイプ | 理由 |
| --- | --- | --- | --- |
| 対象期間 | 2026年1月〜12月 | 2026年8月〜2027年6月 | 2026/27シーズンは秋春制で、暦年とずれる |
| 配色 | クリーム地＋`#4B2E83` | 既存の紫グラデーション地＋紙の面 | 入口ページ・年間スケジュール・タイムラインと同じ系統に寄せた |
| 大会 | J1 / ACL | J1 / ACL / 天皇杯 / ルヴァン | `matches.json` に4大会ある |
| 大会色 | `#4B2E83` / `#0E8E86` | `#7b0064` / `#116b66` / `#8a6212` / `#b2165b` | 既存の大会リボン色を土台に、白文字で4.5:1以上になる濃さへ寄せた |
| 日付の文字色 | 一律 `rgba(30,27,36,.6)` | 明るい帯は黒、中2日以下（赤）は白 | `#C8402E` に黒文字は3.5:1で不足するため |
| スクロール | 画面内の入れ子スクロール | ページ全体のスクロール＋貼り付くミニマップ | iOS Safariで入れ子スクロールとアドレスバーがぶつかるのを避ける |

## 実データで分かったこと

`public/data/matches.json`（57件）で描くと次の状態になる。

- 中3日が25区間、中2日以下が10区間。中2日以下は10月・11月と2027年2月〜4月に集中する。
- 57件のうち26件が `status: tentative`、うち17件は `match_date` を持たず `date_candidates` だけ。
  土日の2日組が多く、そのままだと「どちらの日で数えるか」で中n日が変わる。
- 2027年1月2日〜2月8日の38日間が中断期間にあたる。

## 未確定日程の扱い

`match_date` が無い試合は候補日すべてに点線の箱を置き、`候補1/2` `候補2/2` を添える。
候補日も「試合が入りうる日」として間隔の計算に入れるため、結果として**いちばん詰まった読み方**になる。
確定した間隔と区別できるよう、未確定の試合に接する区間には斜線を掛けている。

例: 2027年2月13日・14日（第21節の候補）と2月16日（ACL）のあいだは、13日開催なら中2日、
14日開催なら中1日になる。プロトタイプは中1日として描き、斜線で「確定ではない」を示す。

## 判断が要るところ

1. **中断期間の色**。2027年1月2日〜2月8日の38日間は、指示どおりなら「中5日以上＝安全（緑）」になる。
   実際にはオフに近い期間で、中6日と同じ緑にすると意味が薄い。`中14日以上` を中立（グレー）にする
   6段目を足すかどうか。
2. **斜線の量**。2027年2月以降はJ1がほぼ未確定のため、日の半分弱（263日中146日）が斜線になる。
   斜線を出すのは未確定の試合に接する区間だけに絞る、確定分だけを描く切り替えを置く、などの案がある。
3. **幅320pxでの対戦相手名**。大会名バッジを右端に固定する指示のため、
   `ニューカッスル・ジェッツ` `ブリーラム・ユナイテッド` の2件は省略記号になる。
4. **本番の置きどころ**。別ページにするか、年間スケジュールの表示モードにするか。
   比較は `docs/dense-schedule-calendar.md` の「本番の置きどころ」にある。
