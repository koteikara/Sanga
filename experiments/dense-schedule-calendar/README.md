# 過密日程カレンダー（検証用プロトタイプ）

> **本番ページができました（2026-09-08）。** `public/calendar.html` が公開版で、
> 入口ページの現役グリッドにも並んでいます。ここは引き続き検証用です。
> 見せ方を試すときはここで、公開版に入れるときは `public/` 側を直します。

作成日: 2026-09-08（同日、実機確認の指摘を2回反映）

## 目的

2026/27シーズンの試合と試合の「間隔」の詰まり具合を、スマートフォンでスクロールしながら
把握できるかを確かめる。設計の意図と用語は `docs/dense-schedule-calendar.md` を正とする。

文章と静的モックアップだけでは決まらない次の点を、実データで触って確かめるためのもの。

| 確認したいこと | 見るところ |
| --- | --- |
| 全日を並べて破綻しないか（334日・約9,900px） | 全体をスクロール |
| 危険度の色分けが「過密」を伝えるか | 10月・11月 |
| 月見出しの貼り付きで現在地を見失わないか | 月をまたぐところ |
| ミニマップで年間の density を掴めるか | 右端の帯 |
| 未確定日程の見せ方が誤解を生まないか | 2027年2月〜5月の点線の箱と斜線 |
| 中断期間（中14日以上）を中立にした見え方 | 2027年1月 |
| 狭い画面で対戦相手名が読めるか | 幅320pxでACL勢の長い名前 |

## 確認方法

GitHub Pagesで次を開く。

```text
https://koteikara.github.io/Sanga/experiments/dense-schedule-calendar/prototype.html
```

`fetch` で日程JSONを読むため、ローカルではファイルを直接開かずHTTP経由で開く。

```bash
python3 -m http.server 8000
# http://localhost:8000/experiments/dense-schedule-calendar/prototype.html
```

日程は複製を置かず `public/data/matches.json` の正本をそのまま読む。GitHub Pagesでは
`public/` が直下に展開され、手元ではリポジトリ直下が根になるため、`../../data/matches.json` と
`../../public/data/matches.json` を順に試す。手元で開くと前者が1回404になるが、後者で読めていれば正常。
作り手アイコンとネビュラも同じ理由で `public/` 側へ読み替える。共通トップバーのCSS
（`../../assets/topbar.css`）だけは読み替えができないため、手元ではバーが素のリンクになる。
見た目を確かめるときはGitHub Pagesで開く。

「使い方」は `<dialog>` の `showModal()` で開く。Esc・フォーカスの閉じ込め・閉じたあとの
フォーカス復帰は標準の挙動をそのまま使い、背面のスクロール止めだけ足している。

## 元の指示との違い

添付モックアップからは、実データと既存ページに合わせて次を変えている。

| 項目 | モックアップ | このプロトタイプ | 理由 |
| --- | --- | --- | --- |
| 対象期間 | 2026年1月〜12月 | 2026年8月〜2027年6月 | 2026/27シーズンは秋春制で、暦年とずれる |
| 配色 | クリーム地＋`#4B2E83` | 入口ページと同じネビュラの地＋紙の面 | 入口ページ・SUPPORTER TIMELINEと同じ地にそろえた |
| トップバー | なし | 公開ページ共通の `assets/topbar.css` | 入口ページへ戻れるようにした。見た目を2か所に持たない。画面には固定しない |
| 説明と凡例 | 画面の上下に置く | 「使い方」パネル（`<dialog>`）へまとめる | 画面をカレンダーへ譲るため |
| 月ジャンプ | 素のボタンを並べる | 枠で囲って並べる。「使い方」ボタンはその囲みの外の一番左 | 見た目を整理するため |
| 大会 | J1 / ACL | J1 / ACL / 天皇杯 / ルヴァン | `matches.json` に4大会ある |
| 大会色 | `#4B2E83` / `#0E8E86` | `#7b0064` / `#116b66` / `#8a6212` / `#b2165b` | 既存の大会リボン色を土台に、白文字で4.5:1以上になる濃さへ寄せた |

| スクロール | 画面内の入れ子スクロール | ページ全体のスクロール＋貼り付くミニマップ | iOS Safariで入れ子スクロールとアドレスバーがぶつかるのを避ける |

## 実データで分かったこと

`public/data/matches.json`（57件）で描くと次の状態になる。

- 中3日が25区間、中2日以下が10区間。中2日以下は10月・11月と2027年2月〜4月に集中する。
- 57件のうち26件が `status: tentative`、うち17件は `match_date` を持たず `date_candidates` だけ。
  土日の2日組が多く、そのままだと「どちらの日で数えるか」で中n日が変わる。
- 2027年1月2日〜2月8日の38日間が中断期間にあたる。
- 日付ボックス263日の内訳は、中2日以下・中3日・中4日で106日、中5〜13日で87日、
  中14日以上（中断期間）で38日、シーズン前後の中立で32日。

## 未確定日程の扱い

`match_date` が無い試合は候補日すべてに点線の箱を置き、`候補1/2` `候補2/2` を添える。
候補日も「試合が入りうる日」として間隔の計算に入れるため、結果として**いちばん詰まった読み方**になる。
確定した間隔と区別できるよう、未確定の試合に接する区間には薄い墨の斜線を掛けている
（`rgba(28,25,34,.12)`、2px幅・6px間隔）。白い斜線にしないのは、中立の帯（`#edeae3`）の上で
見えなくなるうえ、中2日以下（`#c8402e`）の上で白文字のコントラストを下げるため。

例: 2027年2月13日・14日（第21節の候補）と2月16日（ACL）のあいだは、13日開催なら中2日、
14日開催なら中1日になる。プロトタイプは中1日として描き、斜線で「確定ではない」を示す。

## 2回目の実機確認のあとに直したこと（2026-09-08）

1. **トップバーを画面に固定しない。** 通常のフローに置き、スクロールで流れて消えるようにした。
   固定が邪魔になる場面が出てきそうという判断。あわせて `TOOLS` / `ABOUT` の2リンクを
   `SANGA TOOLBOX` 1本にし、アイコンは入口ページと同じく作成者のXへ向けた。
2. **説明と凡例を「使い方」パネルへ移した。** 画面上部の飾りが313px→155pxになり、
   スクロール後は月見出しだけが残る。
3. **月ジャンプを枠で囲って並べ、「使い方」ボタンはその囲みの外の一番左に置いた。**

## 1回目の実機確認のあとに直したこと（2026-09-08）

1. **候補日のHOMEバッジが見えなかった。** `.is-candidate .ha-h` が同じルールで
   `background:currentColor` と `color:var(--paper)` を指定していたため、`currentColor` が
   `--paper` に解決され白地に白文字になっていた。大会色を `--comp` に逃がして直した。
   該当は候補日だけを持つHOMEの8試合（2027年2月13/14日 横浜FM、2月27/28日 東京V、
   3月6/7日 FC東京、3月13/14日 川崎F、4月3/4日 長崎、4月29日 G大阪、5月15/16日 広島、
   5月29/30日 名古屋）。
   なお `matches.json` 側でHOME/AWAYが空なのは、勝ち上がり前提で対戦相手も会場も未定の
   カップ戦8件（天皇杯6・ルヴァン2）だけで、こちらはデータどおり。
2. **地を入口ページと同じネビュラにした。** WebGLが使えなければCSSのぼかしが残る進行的強化。
   `?nebula=off` で見比べられる。
3. **共通トップバーを付けた。** 入口ページへ戻れるようにした（この時点では画面に固定していた）。
4. **文言を作り直した。** 説明を1文に縮め、凡例を `間隔` `大会` `未確定` の3群に分けた。

## 決めたこと（2026-09-08）

- **画面はできるだけカレンダーに使う。** 説明・凡例・注記は「使い方」パネルへ、
  トップバーは固定しない。
- **本番は別ページとして追加する。** 年間スケジュールの表示モードには足さない。
  比較と移植手順は `docs/dense-schedule-calendar.md` の「本番の置きどころ」「本番移植前にやること」にある。
- **中断期間**は6段目 `中14日以上` として中立（グレー）にした。中n日の文字が付くため、
  シーズン前後の中立とは読み分けられる。
- **斜線**は薄い墨で細かくした。2027年2月以降はJ1がほぼ未確定のため、
  日付ボックス263日のうち146日が斜線になるが、色の判別を邪魔しない濃さにしている。

## 残っているところ

1. **幅320pxでの対戦相手名**。大会名バッジを右端に固定する指示のため、
   `ニューカッスル・ジェッツ` `ブリーラム・ユナイテッド` の2件は省略記号になる。
2. **本番移植**。手順は `docs/dense-schedule-calendar.md` の「本番移植前にやること」。
