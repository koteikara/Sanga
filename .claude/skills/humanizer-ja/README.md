# humanizer-ja（取り込み）

AIくさい日本語を人間の書いた文章に直すスキル。取り込み元は
https://github.com/gonta223/humanizer-ja （MIT License）。

`~/.claude/skills/` ではなくリポジトリ内に置いている。このリポジトリの
成果物はほぼ日本語の文章で、書く人・書く道具が変わっても同じ基準で
読めてほしいため。クローンすれば誰でも同じスキルが使える。

## いつ使うか

**公開ページに出る日本語を書いたら、書きっぱなしにしない。**
`public/*.html` の本文、案内、ボタンの文言、エラーの文言が対象。

コードのコメントと設計文書は対象外。あちらは読み手が作る側で、
正確さのほうが大事なため。

## 元との違い

いまのところ無い。上流の SKILL.md をそのまま置いている。
差し替えるときは LICENSE も一緒に持ってくること。
