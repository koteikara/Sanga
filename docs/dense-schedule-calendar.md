## 目的

京都サンガF.C.は2026/27シーズン、J1・天皇杯・ルヴァンカップ・ACLの4大会を並行して戦います。
`public/data/matches.json`（57件）で試合間隔を数えると、次の状態です。

| 中n日 | 区間数 |
| --- | --- |
| 中2日以下 | 10 |
| 中3日 | 25 |
| 中4日 | 3 |
| 中5日以上 | 17 |
| 中断期間（2027-01-02〜02-08） | 1 |

年間スケジュールページは試合カードを並べるため、「試合と試合のあいだが何日空くか」は
カード間の日付を読み比べないと分かりません。この画面は、その間隔だけを主役にします。

対象は、日程の詰まり具合そのものを知りたい利用者です。次の試合がいつかを確認する用途は
年間スケジュールページが担当し、こちらは置き換えません。

## 本番の置きどころ

**別ページとして追加することを推奨します。** 年間スケジュールページの表示モードには足しません。

### 比較

| 観点 | 別ページ | 年間スケジュールの表示モードへ融合 |
| --- | --- | --- |
| 描くもの | 全日（334行）。試合が無い日が主役 | 既存の表示モードは試合カード57件の見た目違い。行数も対象も別物になる |
| 表示列（1〜4列） | 不要 | 意味を持たないため隠す必要がある |
| 絞り込み | 大会・HOME/AWAYで絞ると間隔が変わるため、そもそも噛み合わない | 絞り込み結果に表示モードを適用する現在の方針（`docs/display-modes.md`）と矛盾する。大半のフィルタを無効化する必要がある |
| 色枠状態（赤・水色） | 対象外 | 22pxの行に3pxの枠線と44pxのタップ領域は入らない。無効化が必要 |
| 共有画像生成 | 対象外 | 約9,900pxの縦長を `modern-screenshot` で1枚にする前提がない |
| 既存への影響 | `app.js`・`style.css`・LocalStorage・`validate-app-contract.js` に触れない | 表示モード・表示列・フィルタ・画像生成のDOM契約すべてに条件分岐が増える |
| 入口 | `public/data/tools.json` に1件足すと入口ページへ出る | 既存利用者は設定パネルを開かないと気づかない |
| 保守 | CSS・JSが1組増える。版数（`?v=`）の対象も増える | 既存ファイルが太る |

融合案は「表示モードを足す」ように見えて、実際には表示列・絞り込み・色枠・画像生成を
まとめて無効化した別画面を同じページの中に作ることになります。得られるのは
「ページを増やさない」ことだけで、`AGENTS.md` の「既存利用者の表示設定、カード状態を壊さない」
「日程表示欄をごちゃつかせない」に対する risk のほうが大きいと判断しました。

役割分担の考え方も別ページ側に立ちます。`docs/service-scope.md` は年間スケジュールページを
「試合予定の確認・パーソナライズ・SNS共有」に集中させ、別の問いは別の画面で扱う方針です。
予想スカッド（`public/squad.html`）とSUPPORTER TIMELINE（`public/timeline.html`）も、
`matches.json` を共有しながら独立したページになっています。

### 別ページにする場合の構成案

| 項目 | 案 |
| --- | --- |
| HTML | `public/calendar.html` |
| CSS / JS | `public/assets/calendar.css`、`public/assets/calendar.js` |
| データ | `public/data/matches.json`（正本を共有。新しい公開JSONは作らない） |
| 入口 | `public/data/tools.json` に `section: "live"` で1件追加し、`assets/thumbs/` にスクリーンショットを置く（`docs/site-index.md`） |
| 検証 | `tools/check-static-assets.mjs` の参照・版数チェックに乗る。DOM契約の検証を足すかは実装時に判断する |
| LocalStorage | 使わない。個人状態を持たない画面にする |

ページ間の相互リンクは置きません。現在の公開ページ（年間スケジュール・予想スカッド・
SUPPORTER TIMELINE）はいずれも相互リンクを持たず、導線は入口ページに集約されています。

## 画面構成

上から順に、見出し、月ジャンプ、凡例、リスト＋ミニマップ、注記です。

- **リスト**: 1月〜12月ではなくシーズン（2026年8月〜2027年6月、334日）を縦1本に積む。
- **月見出し**: 月ごとの `section` の先頭に置き、画面上端へ貼り付ける。年と、その月の試合数・
  最短の中n日を出す。月ごとに `section` を分けるのは、次の月に入ったら前の月の見出しを外すため。
- **日付ボックス**: 高さ22px。日付の数字、曜日の丸バッジ、間隔の先頭には「中n日」。
- **試合日ボックス**: 高さ36px。日付、曜日バッジ、`vs 相手`、HOME/AWAYの丸、右端に大会バッジ。
- **ミニマップ**: 右端に貼り付く縦帯。各日の色をそのまま縮小し、表示範囲を枠で示す。
  タップでその位置へ、ドラッグで追従。
- **月ジャンプ**: ミニマップはポインタ専用のため、キーボードと支援技術の導線として月の
  リンクを別に置く。`AGENTS.md` の「キーボード操作とフォーカス表示を保つ」に対応する。

### 曜日バッジ

| 条件 | 明るい面 | 濃い面（中2日以下・試合日） |
| --- | --- | --- |
| 土曜 | 青丸に白文字 | 白丸に青文字 |
| 日曜・祝日 | 赤丸に白文字 | 白丸に赤文字 |
| 平日 | 枠線のみの丸 | 白い枠線のみの丸 |

濃い面で反転するのは、赤い日曜バッジを赤い危険色の上に置くと沈むためです。

### HOME/AWAYバッジ

対戦相手名の直後。HOMEは白丸に大会色の「H」、AWAYは白い縁取りだけの丸に白の「A」。
`home_away` が空の試合（勝ち上がり前提のカップ戦など）はバッジを出しません。

## 危険度の決め方

試合が無い日が連続する区間を1つの「間隔」として扱い、その長さをそのまま中n日にします。
指示にある `中n日 = 次の試合日 − 前の試合日 − 1` と同じ値になり、
画面に描いた試合日と必ず一致します。

| 中n日 | 危険度 | 色 |
| --- | --- | --- |
| 中2日以下 | 危険 | `#c8402e` |
| 中3日 | 注意 | `#e08a2e` |
| 中4日 | やや注意 | `#e3b23c` |
| 中5日以上 | 安全 | `#7fa687` |
| 前後どちらかに試合が無い期間 | 中立 | `#edeae3` |

区間内のすべての日を同じ色にします。グラデーションにはしません。

色だけに頼らないよう、区間の先頭の日に「中n日」を文字でも出します。
試合日が連続して間の日が無い場合（中0日）は文字を置く行が無いため、
後ろの試合日ボックスに「中0日」の印を付けます。

## 未確定日程の扱い

`matches.json` 57件のうち26件が `status: tentative` で、うち17件は `match_date` を持たず
`date_candidates`（多くは土日の2日組）だけを持ちます。

- 候補日すべてに点線の試合日ボックスを置き、`候補1/2` `候補2/2` を添える。
- 候補日も「試合が入りうる日」として間隔の計算に入れる。結果としていちばん詰まった読み方になる。
- 未確定の試合に接する区間には斜線を掛け、確定した間隔と区別する。

例: 2027年2月13日・14日（第21節の候補）と2月16日（ACL）のあいだは、13日開催なら中2日、
14日開催なら中1日です。中1日として描き、斜線で確定でないことを示します。

`AGENTS.md` の「不確定情報は `tentative`、候補日、注記で明示する」に対応する扱いです。

## 祝日

内閣府「国民の祝日について」の令和8年（2026年）・令和9年（2027年）を使います。
祝日法第3条第2項・第3項による「休日」（2026-05-06、2026-09-22、2027-03-22）も含みます。

- 出典: https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html
- 機械可読版: https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv
- 確認日: 2026-09-08

令和10年（2028年）分は令和9年2月に公表されます。シーズンが2028年へ伸びる場合は追加が必要です。
出典と利用条件の記録は `docs/source-and-license.md` を正とします。

## 検証

プロトタイプ段階では次を確認しました（2026-09-08、Chromium・幅320/390/430px）。

- 334日・71ボックス（確定40＋候補31）を描き、横スクロールが出ないこと。
- 月見出しが画面上端に貼り付き、次の月で入れ替わること。
- ミニマップの表示範囲枠がスクロールに追従し、タップとドラッグで移動できること。
- 幅320pxで対戦相手名が省略記号になるのは12文字の2件（`ニューカッスル・ジェッツ`、
  `ブリーラム・ユナイテッド`）だけであること。
- `npm run check` が全項目成功すること（`public/` を変更していないため既存検証に影響しない）。

実機（iPhone Safari・Android Chrome）の確認は未実施です。本番移植前に
