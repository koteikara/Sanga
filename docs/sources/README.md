## 新しい素材を置く前の必須記録

素材を追加するPRには、次をPR本文と `docs/source-and-license.md` に記録します。

- 元ページの名称とURL
- 権利者または配布者
- 取得日・確認日
- 利用先
- 加工内容
- ライセンスまたは利用条件
- 許諾の有無と確認方法
- 再配布できる根拠

権利状態を確認できない画像は追加しません。公式サイトの画像を利用する場合も、非営利・非公式・出典表記だけで利用可能とは判断しません。

## 運用原則

- 元画像そのものを `public/` 配下に置いて再配布しません。
- `docs/sources/` も公開リポジトリから閲覧・取得できるため、非公開化や再配布防止が必要な素材はこのディレクトリにも置きません。
- 認証情報、個人情報、購入素材、再配布禁止素材は置きません。
