# 元素材の置き場

公式サイトから取得した元素材を置くディレクトリです。ここに置いたファイルは加工の入力として使い、**そのまま公開はしません**（`public/` 配下へは加工後のファイルだけを置きます）。

## 置くファイル

| ファイル名 | 内容 |
| --- | --- |
| `players-numbers.png` | 公式の背番号一覧画像。ここから背番号タイルを切り出して `public/assets/players/<背番号>.webp` を作る |
| `players-roster.txt` | 公式サイトの選手一覧をコピーして貼り付けたテキスト。ポジション・日本語名・国籍の入力元にする |
| `players-roster.png` | 選手一覧のスクリーンショット。テキストで貼るのが難しい場合はこちら |

拡張子は `.png` でも `.jpg` でも構いません。ファイル名だけ合わせてください。

## 注意

- 元素材は公式サイトの著作物です。**加工物を公開する範囲は、非公式ファンサイトとして妥当な範囲に留めます**
- 元画像そのものを `public/` 配下に置いて再配布することはしません
- 認証情報や個人情報を含むファイルは置かないでください
