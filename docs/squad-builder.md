# 予想スカッド作成ページ 設計メモ

## この文書の目的

京都サンガF.C.の予想スカッド（予想スタメン）を利用者が作成し、SNS共有用の画像として保存できるページの設計を整理します。

年間スケジュールページ（`public/sanga202627season.html`）とは独立した公開済みページです。既存ページのHTML、CSS、JavaScript、公開JSONは変更しません。

`public/squad.html` として公開しています。`experiments/squad-builder/` には、デザイン見本と検証用のプロトタイプを残しています。

## 利用者の操作の流れ

1. フォーメーションを選ぶ
2. 選手を選ぶ
3. 位置を微調整する
4. 画像を作成して保存する

### フォーメーション

プリセットに加えて、枠にとらわれず自由に配置できるモードを用意します。

プリセットは16種類に自由配置を加えた17種類です。4バック（4-4-2、4-4-1-1、4-2-3-1、4-3-3、4-1-4-1、4-3-1-2、4-1-2-1-2、4-2-2-2、4-5-1）、3バック（3-4-2-1、3-4-3、3-5-2、3-6-1）、5バック（5-3-2、5-4-1、5-2-3）を用意しています。

座標は `public/assets/squad-formations.js` に持ちます。列を作る補助関数で組み立てるため、追加や調整は数値の変更だけで済みます。

ポジション表記は **GK / DF / MF / FW の4種類だけ**にします。LSBやCMFのような細かい表記は使いません。

### マスコット

背番号一覧に含まれる 83 PURSA と 510 KOTONO はマスコットです。ネタ枠として選べるようにしますが、既定では選手一覧に表示せず、表示の切り替えで出します。データ側では `isMascot` で区別します。

## デザイン

### 選手カード

FIFA Ultimate Team のカードを参考にしていますが、意匠をそのまま模倣することは避け、配色をサンガの紫と金でオリジナルに寄せています。

カードの構成は次のとおりです。

- 盾型のシルエット。上辺の中央にV字の切り欠き、丸めた上角、垂直に近い側面、下部で中央へ収束する形
- 左肩に背番号（FUTのレーティング枠にあたる位置）とポジション区分
- 中央に背番号タイルの画像
- 下部に名前（ローマ字、任意で日本語名を併記）と国籍の旗

盾の形はSVGの `clipPath`（`objectBoundingBox`）で定義し、カードの外枠と中面で共有します。形を変えるときはこのパスの数値だけを変更します。

装飾は1枚のSVGにまとめてデータURIでCSSから適用しています。内容は次のとおりです。

- 斜めのスウッシュ（金色の光沢リボン3本）
- 内側の二重枠
- クリスタル状の破片
- 全体にかかる光沢
- 分割線中央のひし形と、下部中央の紋章

### 国籍の旗

国旗の絵文字は環境によって表示されないため、旗をSVGで描いてデータURIとしてCSSに埋め込みます。現在は日本、ブラジル、韓国を用意しています。国コードがCSSクラス（`.flag-jp` など）に対応するため、新しい国籍はSVGを1つ足すだけで対応できます。

### 寸法の考え方

カードの大きさは固定値ではなく、ピッチの実寸から計算して割り当てます。スタイルによって余白や枠の太さが変わるとピッチの高さも変わるため、固定値ではカードやポジション名がはみ出すためです。

カード内部の文字や余白はカード幅を基準とするコンテナクエリで指定しており、カードが伸縮しても内部の比率は崩れません。

名前は枠に収まらない場合、まず文字サイズを段階的に縮小し、それでも収まらないときだけ横方向の圧縮で吸収します。盾は下ほど細くなるため、行ごとに使える幅の比率を変えています。

### スタイル

キャンバスの `data-style` 属性で切り替えます。スタイルの実体はCSSのブロックとヘッダー画像だけなので、追加は「ヘッダー画像1枚＋CSS1ブロック」で済みます。

| スタイル | 特徴 |
| --- | --- |
| モダン | 紫のグラデーションに金の見出し。既定 |
| ヴィクトリアン | セリフ体の装飾見出し、ダマスク風の連続模様、外周の二重罫と角飾り |
| グラフィティ | ペンキの飛散（不規則な輪郭のだまり、飛沫、垂れ、刷毛の帯）、太い黒フチの文字 |
| サイバーコア | グリッドと走査線、等幅フォント、色収差、角を切り欠いた枠 |
| ヴェイパーウェーブ | 藤色から紫のグラデーション、走査線、カタカナの見出し |
| シンセウェーブ | 地平線グリッド、ネオンの発光 |
| スクラップブック | 紙の質感、切り抜き文字の見出し、テープ、傾いた貼り付け |
| シンプル | 装飾を排し、内容だけを伝える。ピッチ外を暗く落としてピッチへ視線を集める地色に文字だけの見出し、選手カードは背番号画像の円と名前・ポジションのみ |

メインカラーは全スタイルで紫に統一し、質感と書体だけをスタイルごとに変えています。シンプルだけは例外で、盾型カード・金枠・光沢・背景の模様を外し、見出しも画像ではなく文字で組みます（構成する要素そのものは他のスタイルと同じです）。

### ヘッダー画像

見出しは画像アセットとして持ちます。Webフォントに依存しないため、画像生成時に見出しが崩れません。

| ファイル | 内容 |
| --- | --- |
| `assets/header-source.html` | モダンの生成元 |
| `assets/header-victorian-source.html` | ヴィクトリアンの生成元 |
| `assets/header-styles-source.html` | 残り5スタイルの生成元 |

シンプルだけは画像を使わず、タイトル文字をそのまま見出しにしています。

### ベンチの見せ方

ベンチは2つの軸で切り替えられます。既定はどちらも従来どおり（チップ・標準）です。

| 軸 | 選択肢 | 内容 |
| --- | --- | --- |
| 見せ方 | チップ / 背番号タイル | チップは背番号＋ローマ字名。タイルはスタメンと同じ背番号画像を角丸の四角で並べ、下に省略名（`nameShort`）を出す |
| 大きさ | 標準 / 大きめ | 大きめは倍率で拡大する。チップは1.35倍、タイルは1.9倍 |

見せ方はキャンバスの `data-bench-format`、大きさは `data-bench-emphasis` で切り替えます。
`:has()` は iPhone Safari 15系に無いため使いません。

大きさは `--bench-emphasis` の倍率として持ち、人数に応じた自動縮小 `--bench-scale` と
掛け算します。こうすると見せ方が増えても、はみ出しを防ぐ仕組みは1本のままで済みます。
倍率を見せ方ごとに変えているのは、`layoutPitch()` がカードの下限（70px）を守るために
ベンチを最大0.2ぶん縮めるためです。同じ倍率だとタイルでは打ち消されて差が出ません。

タイルの「大きめ」はフッターの上限を32%まで使い、そのぶんピッチが狭くなって
カードは小さくなります（420px・控え9人で75.1px→65.6px）。ベンチを目立たせることと
スタメンを大きく見せることは両立しないため、利用者が選べるようにしています。

選んだ設定は保存データに含めます。この項目を持たない古い保存データは、
チップ・標準として読み込みます。

比較検討の経緯と実測値は `experiments/bench-emphasis/README.md` にあります。

### 背番号タイル画像の中央寄せ

タイル画像は背番号とローマ字名を焼き込んだ正方形で、画像ごとに中身が左右へ最大±6%、上下へ最大±4%ずれています。盾型カードでは目立ちにくいものの、円だけで見せるシンプルでははっきり分かります。補正は全スタイル共通で掛けており、`tools/measure-tile-offsets.mjs` で画像ごとの上下左右のずれを測り、`public/assets/squad-tile-offsets.js` として持たせています。画像を差し替えたら再生成してください。

文言や色を変えるときは生成元のHTMLを編集し、PNGを再出力します。

### ピッチ

上辺を狭めた台形のSVGで奥行きを出します。芝のストライプは奥ほど間隔が詰まるよう配置し、センターサークルは楕円、ペナルティエリアとゴールエリアも遠近に合わせた台形にしています。上下の階調、中央やや上の光、周辺減光を重ねています。

## 試合情報

試合は自由入力ではなく、年間スケジュールの公開JSON（`public/data/matches.json`）から選びます。「指定しない」を選べば表示しません。保存データに一覧へ無い文字列が入っていた場合は、その値を選択肢へ足して復元します。

日程ページと同じデータを使うため、表記のゆれが起きません。

## 画面の作り

スマートフォンでの入力時に画面が拡大されて表示幅がずれるのを防ぐため、**フォーム部品の文字は16px以上**にします。16px未満だとフォーカス時に自動拡大されます。

ピッチの高さを確保するため、下部帯は最小限にしています。監督とキックオフの行は置きません。ベンチの空き枠は記号だけにし、見た目は小さいまま当たり判定を広げてタップできるようにしています。

ピッチの高さが変わるとカードの寸法も変わるため、`ResizeObserver` でピッチを監視して配置を計算し直します。

## 投稿者名

誰の予想かがわかるよう、下部帯に投稿者名を表示します。未入力のときは何も出しません。入力値はLocalStorageに保存され、公開JSONには含めません。入力欄には、知られたくない情報を入れないよう注意書きを添えています。

## 画像化するときの制約（iOS Safari）

画像生成は `modern-screenshot` がDOMを複製してSVGの `foreignObject` に描き込む方式のため、
一部のCSSがブラウザによって正しく再現されない。

**キャンバス（`#canvas`）の中では `box-shadow` と `filter: drop-shadow` を使わない。**

iPhone Safari で画像化すると、これらの影が大きくずれて描画され、
「カードの右側に大きな影が出る」「ポジション表示の影が右に寄る」という崩れになる。
実機での切り分け（2026-08-20）で、影を消した場合だけ崩れないことを確認した。
単位の問題ではない（`cqw` を px に変えても再現した）。

そのため以下のようにしている。

- `.card` / `.flag` / `.pos-pill` の影は付けない。
  もともと暗いピッチの上に置かれており、消しても見え方はほとんど変わらない
  （Chromiumでの画素差分 0.00%）
- `.pitch-vignette` は `inset` の `box-shadow` をやめ、
  同じ見え方になる `linear-gradient` 2枚で描いている

影に相当する表現が必要な場合は、`background` のグラデーションなど、
影以外の方法で描くこと。ピッチ外枠の `box-shadow`（スタイルごとに定義）は
現状のまま残しているが、崩れが再発した場合はここも疑う。

## 自動検証

PR時と本番デプロイ前は、`.github/workflows/squad-checks.yml` を共通利用して次を検証します。

- スカッド用JavaScriptと検証スクリプトの構文
- `tools/validate-players.js` による選手JSON
- `tools/validate-squad-contract.mjs` による必須ファイル、DOM、参照、39選手、17フォーメーション、8スタイルの静的契約
- `tools/check-squad-layout.mjs` によるChromium実レイアウト

実ブラウザ検証はスタメン11人を配置した状態で、幅320px・375px・420px、控え0人・5人・9人・12人、17フォーメーション、8スタイルの全組み合わせを対象にし、カードの重なり、ピッチ外へのはみ出し、ベンチの見切れ、ページ内JavaScriptエラーを確認します。失敗した場合、本番デプロイはFTPアップロードへ進みません。

この検証はiPhone SafariのPNG生成やタッチ操作を代替しません。UI、CSS、画像生成を変更した場合は `docs/ai/SQUAD_BROWSER_CHECKLIST.md` に沿って実機確認を続けます。

### 選手データについて

国籍は、いただいた選手一覧の出生地をもとにしています（ブラジル→br、大韓民国→kr、国内の都道府県→jp）。**出生地と国籍は必ずしも一致しない**ため、判断が分かれる選手は確認のうえ決めています。36 ファンティーニ 燦 はイタリア出身ですが `jp` です。

背番号90 ハウス は背番号一覧画像に含まれないため、`tools/compose-player-number.js` で既存タイルの字形を組み合わせて作成しました。数字も名前も元画像の字形を使っています。
