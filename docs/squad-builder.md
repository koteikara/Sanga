# 予想スカッド作成ページ 設計メモ

## この文書の目的

京都サンガF.C.の予想スカッド（予想スタメン）を利用者が作成し、SNS共有用の画像として保存できるページの設計を整理します。

年間スケジュールページ（`public/sanga202627season.html`）とは独立した別ページとして作ります。既存ページのHTML、CSS、JavaScript、公開JSONは変更しません。

`public/squad.html` として公開しています。`experiments/squad-builder/` には、デザイン見本と検証用のプロトタイプを残しています。

## 利用者の操作の流れ

1. フォーメーションを選ぶ
2. 選手を選ぶ
3. 位置を微調整する
4. 画像を作成して保存する

## 決定事項

### 選手データ

| 項目 | 決定内容 |
| --- | --- |
| 取得方法 | 手入力。公式サイトを参照し、既存の日程データと同じくスプレッドシートで管理する |

### 選手の写真

| 項目 | 決定内容 |
| --- | --- |
| 素材 | 公式の背番号一覧画像から、背番号タイルを切り出して使う |

顔写真ではなく背番号タイルを使う判断は、素材の扱いが単純になることと、切り出しを機械的に行えることによります。

### フォーメーション

プリセットに加えて、枠にとらわれず自由に配置できるモードを用意します。

プリセットは主要な5〜6種類を想定します（4-4-2、4-2-3-1、4-3-3、3-4-2-1、3-5-2 など）。

### マスコット

背番号一覧に含まれる 83 PURSA と 510 KOTONO はマスコットです。ネタ枠として選べるようにしますが、既定では選手一覧に表示せず、表示の切り替えで出します。データ側では `isMascot` で区別します。

## デザイン

### 選手カード

FIFA Ultimate Team のカードを参考にしていますが、意匠をそのまま模倣することは避け、配色をサンガの紫と金でオリジナルに寄せています。

カードの構成は次のとおりです。

- 盾型のシルエット。上辺の中央にV字の切り欠き、丸めた上角、垂直に近い側面、下部で中央へ収束する形
- 左肩に背番号（FUTのレーティング枠にあたる位置）とポジション区分
- 中央に背番号タイルの画像
- 下部に名前（ローマ字、任意で日本語名を併記）と国籍の旗

盾の形はSVGの `clipPath`（`objectBoundingBox`）で定義し、カードの外枠と中面で共有します。形を変えるときはこのパスの数値だけを変更します。

装飾は1枚のSVGにまとめてデータURIでCSSから適用しています。内容は次のとおりです。

- 斜めのスウッシュ（金色の光沢リボン3本）
- 内側の二重枠
- クリスタル状の破片
- 全体にかかる光沢
- 分割線中央のひし形と、下部中央の紋章

### 国籍の旗

国旗の絵文字は環境によって表示されないため、旗をSVGで描いてデータURIとしてCSSに埋め込みます。現在は日本、ブラジル、韓国を用意しています。国コードがCSSクラス（`.flag-jp` など）に対応するため、新しい国籍はSVGを1つ足すだけで対応できます。

### 寸法の考え方

カードの大きさは固定値ではなく、ピッチの実寸から計算して割り当てます。スタイルによって余白や枠の太さが変わるとピッチの高さも変わるため、固定値ではカードやポジション名がはみ出すためです。

カード内部の文字や余白はカード幅を基準とするコンテナクエリで指定しており、カードが伸縮しても内部の比率は崩れません。

名前は枠に収まらない場合、まず文字サイズを段階的に縮小し、それでも収まらないときだけ横方向の圧縮で吸収します。盾は下ほど細くなるため、行ごとに使える幅の比率を変えています。

### スタイル

キャンバスの `data-style` 属性で切り替えます。スタイルの実体はCSSのブロックとヘッダー画像だけなので、追加は「ヘッダー画像1枚＋CSS1ブロック」で済みます。

| スタイル | 特徴 |
| --- | --- |
| モダン | 紫のグラデーションに金の見出し。既定 |
| ヴィクトリアン | セリフ体の装飾見出し、ダマスク風の連続模様、外周の二重罫と角飾り |
| グラフィティ | ペンキの飛散（不規則な輪郭のだまり、飛沫、垂れ、刷毛の帯）、太い黒フチの文字 |
| サイバーコア | グリッドと走査線、等幅フォント、色収差、角を切り欠いた枠 |
| ヴェイパーウェーブ | 藤色から紫のグラデーション、走査線、カタカナの見出し |
| シンセウェーブ | 地平線グリッド、ネオンの発光 |
| スクラップブック | 紙の質感、切り抜き文字の見出し、テープ、傾いた貼り付け |

メインカラーは全スタイルで紫に統一し、質感と書体だけをスタイルごとに変えています。

### ヘッダー画像

見出しは画像アセットとして持ちます。Webフォントに依存しないため、画像生成時に見出しが崩れません。

| ファイル | 内容 |
| --- | --- |
| `assets/header-source.html` | モダンの生成元 |
| `assets/header-victorian-source.html` | ヴィクトリアンの生成元 |
| `assets/header-styles-source.html` | 残り5スタイルの生成元 |

文言や色を変えるときは生成元のHTMLを編集し、PNGを再出力します。

### ピッチ

上辺を狭めた台形のSVGで奥行きを出します。芝のストライプは奥ほど間隔が詰まるよう配置し、センターサークルは楕円、ペナルティエリアとゴールエリアも遠近に合わせた台形にしています。上下の階調、中央やや上の光、周辺減光を重ねています。


画像の読み込み制限があるため、`file://` ではなくローカルサーバ経由で開いてください。



### 選手データについて

国籍は、いただいた選手一覧の出生地をもとにしています（ブラジル→br、大韓民国→kr、国内の都道府県→jp）。**出生地と国籍は必ずしも一致しない**ため、判断が分かれる選手は確認のうえ決めています。36 ファンティーニ 燦 はイタリア出身ですが `jp` です。

背番号90 ハウス は背番号一覧画像に含まれないため、`tools/compose-player-number.js` で既存タイルの字形を組み合わせて作成しました。数字も名前も元画像の字形を使っています。
