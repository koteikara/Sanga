# ドキュメントアーカイブ

## 目的

完了済みの計画、過去のAI作業記録、未導入の調査・連携案を、現行仕様や現在の作業指示と区別して保管します。

## 利用ルール

- 通常の実装前必読文書には含めません。
- 現在の仕様・手順は `AGENTS.md` と `docs/documentation-policy.md` から辿ります。
- 過去の判断理由、検証結果、変更経緯を確認するときだけ参照します。
- アーカイブ内のコマンド、件数、ファイル位置、作業指示を現在も有効と仮定しません。
- アーカイブ文書を現行へ戻す場合は、実装と照合して別PRで更新します。
