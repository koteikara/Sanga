## 位置づけ

`docs/production-inventory-audit.md` に「現行機能ではないため、仕様変更や改修の対象にはしません」と記載していました。

2026-09-08の入口ページ整備で `public/data/tools.json` の `live` に載り、`public/index.html` から導線が通ったため、

## 作り直す理由

現行ツールは、ほぼ使われていません。原因を実地で調べたところ、**投稿が誰にも見つからない形で出力されていた**ことが分かりました。

### 誰も見ていないタグを出力していた

Yahoo!リアルタイム検索（Xをログインなしで検索できる）で、2026-09-09に確認した結果です。

| タグ | 投稿 |
| --- | --- |
| `#サンガガチャ交換` | あり（2026-08-29、08-30 ほか） |
| `#サンガグッズ交換` | あり（2026-08-23、08-29、08-30 ほか） |
| `#京都サンガ` | 交換投稿で頻出 |
| **`#京都サンガ交換希望`**（現行ツールが出力する） | **0件（「一致する情報は見つかりませんでした」）** |
| `#Jリーグ交換` | 0件 |

京都サンガのグッズ交換はXで現に動いています。現行ツールだけが、実在しないタグを吐いていました。

### 入力を自由文にしていた

現行ツールは「譲るもの」「求めるもの」を1行の自由文で受け取り、その文字列をそのままハッシュタグにします
（`public/TradePost/script.js` の `#${offerItem.replace(/ /g, "")}`）。
`#ホーム浦和戦Sメイン` のような、検索されないタグが生成されます。

実際の投稿は後述のとおり**商品名＋背番号の集合**です。1行の自由文では表現できません。

## Xでの交換の実態

2026-09-09に、Yahoo!リアルタイム検索で `#サンガガチャ交換` `#サンガグッズ交換` および
`京都サンガ 交換 ガチャ` を確認しました。以下は実際の投稿から読み取った書き方です。

```text
🟣ガチャ交換🟣 譲）ユニ型缶バッジ 2 求）同種44
譲）ユニ型キーホルダー 2、23、38 求）同種44
次戦、日産スタジアムorホーム柏レイソル戦での交換🉑          （2026-08-30）

換、買取 (譲) ユニホーム缶バッチ 2.8.34.50 キーホルダー 17.29.31 (求) 9 、定価   （2026-08-23）

RENCAブース 参加賞ステッカー 譲: 31 平賀 求: 25 尹 48 中野      （2026-08-30）

8/29福岡戦で発売された京都サンガガチャ(ラバーユニフォーム)10番(1st.2nd)、11番(2nd)を
買取させてくださる方                                              （2026-08-29）
```

読み取れる文法は次のとおりです。

| 要素 | 実際の書き方 |
| --- | --- |
| 単位は背番号 | `譲) 2.8.34.50` `求) 9`。商品名は1回だけ書き、あとは番号を並べる |
| 区切り | `.`（ドット）が最多。`、`（読点）も使われる |
| 商品は種類で呼ぶ | ユニ型缶バッジ／ユニ型キーホルダー／ラバーユニフォーム／参加賞ステッカー |
| 表記ゆれがある | 「ユニ型缶バッジ」と「ユニホーム缶バッチ」が同じ商品を指している |
| 1st / 2nd | `10番(1st.2nd)`、`求)1st:2.7.18` |
| 「同種」 | `求）同種44` ＝ 直前に挙げた商品と同じものの44番。1投稿に複数商品を並べたときの省略 |
| 受け渡しは試合 | `次戦、日産スタジアムorホーム柏レイソル戦での交換🉑` |
| 発売も試合に紐づく | `8/29福岡戦で発売された` |
| 交換だけではない | `換、買取`／`定価`／`300円で交換` |

**この2軸——商品×背番号と、試合——を、このリポジトリは正本として持っています。**
`public/data/players.json`（背番号つき、有効39件）と `public/data/matches.json`（57件）です。

> 出典はYahoo!リアルタイム検索経由の確認です。投稿者・日付・商品名まで具体的に取れているため実在は堅いと判断していますが、
> 商品の正式名称は公式の表記と突き合わせる余地があります。「未確定事項」を参照してください。

## 他ジャンルの成功例

| [おけぴネット](https://okepi.net/all.aspx/)（2005年〜） | 項目を構造化して並べる。価格の線を明示する |
| r/hardwareswap | タイトルの書式を固定し、機械可読にする |
| [お取引ガイド](https://note.com/rinne_pon/n/n72dbe2929dc0)、[処方箋](https://note.com/sirasememo/n/nabdd2af2dcb2) | **募集文の締めに「検索からお気軽にお声かけください」を入れる。**フォロワー外に届く経路は、タグではなく「検索した人が知らない相手に声をかける」慣習のほう |

## 設計

**「投稿をつくる」と「募集をさがす」の二枚看板にします。**
作るだけでは、投稿しても見つけてもらえるまで待つしかありません。探す側を持つことで、
既に出ている投稿へ自分から届きます。**探す側は導入初日から機能します。**タグの普及を待ちません。

### つくる

1. 商品を選ぶ（`goods.json` から）
2. 種別を選ぶ（1st / 2nd など。商品が持つときだけ表示）
3. 譲る背番号を選ぶ（`players.json` から複数選択）
4. 求める背番号を選ぶ（複数選択、または「番号は問わない（同種）」）
5. 受け渡しの試合を選ぶ（`matches.json` の今後の試合から複数選択）、郵送の可否
6. 補足（任意の自由文）
7. 投稿文と画像を出力する

### さがす

同じ選択のまま、いま出ている募集への検索リンクを出します。

| 行き先 | 理由 |
| --- | --- |
| Yahoo!リアルタイム検索 | Xの投稿をログインなしで検索できる |
| X検索 | ログインしていれば新着順で追える |

### タグの方針

**新しいタグを発明しません。** 実在が確認できたタグだけを `goods.json` に持ち、そこから出力します。
現行の `#京都サンガ交換希望` は削除します。

## `goods.json` のスキーマ

商品は選択式にします。表記ゆれを消すことが目的なので、自由入力にはしません。
そのぶん、新商品が出たら追加する運用が必要です。

```json
{
  "updatedAt": "2026-09-09",
  "hashtags": ["#サンガガチャ交換", "#サンガグッズ交換", "#京都サンガ"],
  "goods": [
    {
      "id": "uni-can-badge",
      "name": "ユニ型缶バッジ",
      "aliases": ["ユニホーム缶バッチ", "ユニフォーム缶バッジ"],
      "unit": "number",
      "variants": ["1st", "2nd"],
      "tags": ["#サンガガチャ交換"],
      "tentative": false,
      "source": "https://search.yahoo.co.jp/realtime/",
      "checkedAt": "2026-09-09"
    }
  ]
}
```

| フィールド | 意味 |
| --- | --- |
| `id` | 内部ID。LocalStorageと検索クエリの組み立てに使う。変更しない |
| `name` | 投稿文に出す正式名称 |
| `aliases` | 表記ゆれ。**検索クエリの組み立てに使う**（`ユニ型缶バッジ OR ユニホーム缶バッチ`） |
| `unit` | `number`（背番号で指定する）／ `none`（番号がない商品） |
| `variants` | 種別。空配列なら種別欄を出さない |
| `tags` | この商品で使う実在タグ |
| `tentative` | 正式名称が未確認なら `true`。UIに注記を出す |
| `source` / `checkedAt` | 出典と確認日（`AGENTS.md`の方針） |

`aliases` は表記ゆれを**投稿側では消し、検索側では拾う**ために持ちます。自分は正式名称で書き、
他人の揺れた表記も見つけられる状態にします。

## 出力フォーマット

実際の投稿の書き方に合わせます。背番号はドット区切り、商品名は1回だけです。

```text
【交換】ユニ型缶バッジ（1st）
譲 2.8.34.50
求 9.17

9/13(日) ホーム柏戦 / 郵送も可
検索からお気軽にお声かけください

#サンガガチャ交換 #京都サンガ
```

- 「求」の番号を問わないときは `求 同種` とします。「同種」は実際の投稿で使われている語で、
  1つの投稿に複数の商品を並べたときに「いま挙げた商品と同じもの」を指しています
  （`譲）ユニ型缶バッジ 2 求）同種44`）。このツールは1投稿1商品なので、番号を問わない意味で使います。
  **この用法が誤解なく伝わるかは未確認です。**「未確定事項」を参照してください。
- 試合は `matches.json` の `match_date` と `opponent`、`home_away_label` から組み立てます。
- 締めの一文は既定で入れ、外せるようにします。

### 文字数

Xの上限は重み付き280です。日本語は1文字あたり2、半角は1として数えます。
現行ツールは生の `length` を140で比較しており、半角混じりの投稿を不必要に弾きます。
**重み付きで数え直します。**

### 画像

背番号の羅列はテキストだと読みにくいため、譲・求を並べた画像も出します。
予想スカッドと同じ方式（ブラウザ内生成）を想定します。`public/assets/vendor/modern-screenshot` が使えます。

> iOS Safari対策として、画像化対象の要素に `box-shadow` と `filter: drop-shadow` を使いません（`AGENTS.md`）。

## LocalStorage

端末内にだけ持ちます。公開JSONへは書きません。

| キー | 内容 |
| --- | --- |
| `sanga.tradePost.draft.v1` | 最後の入力内容（商品、種別、譲・求の番号、試合、締め文の有無） |

既存キーは持っていないため、移行は不要です。取引の進捗管理（`推しグッズ交換メーカー` が持っている機能）は
**今回の範囲外**とし、必要になってから足します。

## 対象外

| やらないこと | 理由 |
| --- | --- |
| チケットの求・譲 | 京都サンガのホームゲームチケットは特定興行入場券（[チケット総合案内](https://www.sanga-fc.jp/ticket)）。定価超の反復継続的な有償譲渡は[チケット不正転売禁止法](https://www.caa.go.jp/policies/policy/consumer_research/white_paper/2020/white_paper_column_11.html)違反にあたる。公式リセールがある。現行ツールのプレースホルダ「定価＋手数料」は定価超であり、例文として出さない |
| 募集の掲載・保管 | 静的サイトのため投稿を預かる先がない。個人情報と通報対応の責任も負えない |
| 取引の仲介・評価 | 同上 |
| 新しいハッシュタグの提唱 | 現行ツールで失敗している |

## 検証

プロトタイプ段階では、`docs/ui-prototype-workflow.md` の確認観点に加えて次を見ます。

- 商品を選ぶと種別欄の出し分けが変わる
- 背番号を複数選んで、ドット区切りで並ぶ
- 「同種」を選ぶと求の番号選択が切り替わる
- 試合が `matches.json` の今後の試合だけから選べる
- 文字数が重み付き280で数えられている
- 生成した投稿文にタグが実在するものだけ入る
- 検索リンクがYahoo!リアルタイム検索とXの両方へ飛ぶ
- スマホ幅で破綻しない、タップ対象が44px程度ある

本番移植時は `npm run check:static`（公開アセットの版数と参照の突き合わせ）を通します。

## 未確定事項

1. **商品の正式名称。** `goods.json` の初期値はXの投稿から起こしており、公式の表記と一致していない可能性があります。
   `tentative: true` を付けた項目は、公式オンラインショップまたはクラブの告知で確認してから外します。
2. **商品マスタの更新運用。** ガチャは試合ごとに新商品が出ます（`8/29福岡戦で発売された`）。
   誰がいつ追加するかを決めていません。`matches.json` の更新に合わせる案があります。
3. **画像を出すかどうか。** プロトタイプで見てから決めます。テキストだけで足りるなら足しません。
4. **`TradePost/` に `index.html` がない問題。** `/TradePost/` で到達できません
   （`docs/production-inventory-audit.md` の未解決課題）。本番移植時に併せて直すか、別途決めます。
5. **タグの実地確認。** 本文書のタグ調査はYahoo!リアルタイム検索経由です。X本体でも一度確認します。
6. **「同種」の使い方。** 実際の投稿では「いま挙げた商品と同じもの」を指しています。
   1投稿1商品のこのツールで「番号を問わない」の意味に使って伝わるかは確認できていません。
   伝わらないようなら、別の言い方にするか、この選択肢自体をやめます。
